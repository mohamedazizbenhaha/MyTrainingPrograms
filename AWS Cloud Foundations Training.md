### AWS Cloud Foundations Training Program

#### Program Overview
- **Target Audience**: Beginners in cloud computing, IT enthusiasts, or professionals seeking AWS entry-level skills.
- **Prerequisites**: None; suitable for newcomers.
- **Delivery Format**: Instructor-led, online or in-person, with access to AWS Academy platform for videos, demos, labs, and resources.
- **Objectives**: Understand cloud concepts, economics, infrastructure, security, networking, compute, storage, databases, architecture, scaling, and prepare for certification.
- **Certification Alignment**: Prepares for AWS Certified Cloud Practitioner; includes knowledge checks, labs, and a new prep module with practice exams.
- **Total Duration**: 30 hours.
- **Assessment**: Knowledge checks (quizzes) per module, hands-on labs and activities, and certification practice.
- **Materials Provided**: AWS Academy videos, student guides, console demos, and lab environments.
- **Pricing Suggestion for Commercialization**: $600 (1800 TND) per participant (group discounts available); includes certification exam voucher option for +$100 (300 TND).
