### AWS Cloud Operations Training Program

#### Program Overview
- **Target Audience**: IT operations professionals, system administrators, and those managing AWS environments.
- **Prerequisites**: AWS Cloud Foundations or equivalent; basic AWS knowledge.
- **Delivery Format**: Instructor-led, online or in-person, with access to AWS Academy platform for student guides, demos, labs, and tools.
- **Objectives**: Understand systems operations, automation, computing servers, scaling, containers/serverless, databases, networking, storage, monitoring, security, resource consumption, and automated deployments.
- **Certification Alignment**: Prepares for AWS Certified SysOps Administrator – Associate (SOA-C02); includes knowledge checks, labs, and a dedicated prep module with practice exams.
- **Total Duration**: 30 hours.
- **Assessment**: Knowledge checks (quizzes) per module, hands-on labs, activities, and certification practice.
- **Materials Provided**: AWS Academy student guides, videos, demos, console walkthroughs, and lab environments.
- **Pricing Suggestion for Commercialization**: $700 (2100 TND) per participant (group discounts available); includes certification exam voucher option for +$150 (450 TND).
