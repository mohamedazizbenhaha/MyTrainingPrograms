### AWS Academy Cloud Architecting Training Program

#### Program Overview
- **Target Audience**: IT professionals, developers, and architects with basic AWS experience (e.g., Cloud Practitioner certified).
- **Prerequisites**: AWS Cloud Foundations or equivalent; understanding of cloud basics.
- **Delivery Format**: Instructor-led, online or in-person, with access to AWS Academy platform for student guides, demos, labs, and tools.
- **Objectives**: Design secure, scalable architectures using AWS services for storage, compute, databases, networking, security, monitoring, automation, caching, decoupling, serverless, data pipelines, and disaster recovery.
- **Certification Alignment**: Prepares for AWS Certified Solutions Architect – Associate (SAA-C03); includes knowledge checks, labs, and a dedicated prep module with practice exams.
- **Total Duration**: 40 hours.
- **Assessment**: Knowledge checks (quizzes) per module, guided and challenge labs, and certification practice.
- **Materials Provided**: AWS Academy student guides, videos, demos, console walkthroughs, and lab environments.
- **Pricing Suggestion for Commercialization**: $800 (2400 TND) per participant (group discounts available); includes certification exam voucher option for +$150 (450 TND).
