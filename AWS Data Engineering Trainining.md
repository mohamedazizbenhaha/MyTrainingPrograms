### AWS Academy Data Engineering Training Program

#### Program Overview
- **Target Audience**: Data professionals, engineers, and analysts interested in building data pipelines on AWS.
- **Prerequisites**: AWS Cloud Foundations or equivalent; basic data concepts.
- **Delivery Format**: Instructor-led, online or in-person, with access to AWS Academy platform for student guides, demos, labs, and tools.
- **Objectives**: Understand data-driven decisions, pipeline design, ingestion, storage, processing (big data/ML), analysis, visualization, security, scaling, and automation.
- **Certification Alignment**: Prepares for AWS Certified Data Engineer – Associate (DEA-C01); includes knowledge checks, labs, and a dedicated prep module with practice exams.
- **Total Duration**: 40 hours.
- **Assessment**: Knowledge checks (quizzes) per module, hands-on labs, activities, capstone project, and certification practice.
- **Materials Provided**: AWS Academy student guides, videos, demos, console walkthroughs, and lab environments.
- **Pricing Suggestion for Commercialization**: $800 (2400 TND) per participant (group discounts available); includes certification exam voucher option for +$150 (450 TND).
